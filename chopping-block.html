How the score works

All rankings use the selected rolling game-day period (fixed UTC−2), including today. VS sums available daily lists. Donations use verified completed-day differences whenever available, replacing partial Today snapshots; weekly totals are never added. Scanner donation dates, event dates, kill observation boundaries and rolling periods follow the game UTC−2 clock. An absent player in a captured daily list is zero; an uncaptured day is unknown for everyone. Kill gains are estimated from an absolute kill observation at/before the start and the latest within the window (each boundary has up to three days of scan tolerance); missing baselines and inconsistent totals remain unknown. Frenzy uses only the latest Frenzy Guilds leaderboard captured in the selected window, never a snapshot outside it or the sum of cumulative snapshots. Frenzy points are event totals as of that capture, not exact gains over the selected days. Missing from that leaderboard is a red flag; known joins on/after the snapshot and other-guild entries are protected. Default weights: VS 30%, donations 25%, Frenzy 30%, kill gains 15%. Positive scores are peer percentiles and zero is zero. If no kill baseline or Frenzy snapshot is available for anyone, that category is omitted and other weights normalized. Incomplete daily coverage makes the ranking an estimate; missing weighted member data, ambiguous identity or a known join during the period marks the member provisional and excludes them from the bottom group. Power and observed outgoing attacks have optional weights, defaulting to zero. War attack counts are observed events, not kills.
